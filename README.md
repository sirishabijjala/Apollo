# 🩺 Doctor Booking Web Application

A full-stack web application for booking and managing doctor consultations.

---

## 🚀 Tech Stack

- **Frontend**: Next.js
- **Backend**: Node.js, Express.js
- **Database**: MySQL
- **API Testing**: Postman
- **Styling**: CSS / Tailwind / Bootstrap

---

## 📦 How to Run the Project

### 1. Clone the Repo

git clone https://github.com/sirishabijjala/Apollo.git
cd Apollo
### 2.Run the Backend
cd Apollo-backend      -------->backend folder

node Server.js
### 3. Run the Frontend
cd apollo-clone      -----> frontend folder
npm run dev

The app should be available at http://localhost:3000

🧪 Sample Data
Add doctors using the Add Doctor form

Use /list-doctor-with-filter endpoint to see all doctors
