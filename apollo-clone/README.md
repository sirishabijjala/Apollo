# Apollo-Clone
# 🩺 Doctor Booking Web Application

A full-stack web application for booking and managing doctor consultations.

---

## 🚀 Tech Stack

- **Frontend**: Next.js, React.js
- **Backend**: Node.js, Express.js
- **Database**: MySQL
- **API Testing**: Postman
- **Styling**: CSS / Tailwind / Bootstrap

---

## 📦 How to Run the Project

1. Clone the Repo
git clone https://github.com/sirishabijjala/Apollo-Clone.git
cd Apollo-Clone
2. Run the Backend
cd Apollo-backend    ----->backend folder
Backend running on port 5000
node Server.js
4. Run the Frontend
cd apollo-clone  ----> frontend folder
npm run dev
The app should be available at http://localhost:3000
